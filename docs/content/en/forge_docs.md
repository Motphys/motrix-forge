## Recommended reading order

New users should read chapters 0–9 in order, then use chapter 10 when an operator is unavailable, a target order is wrong, inertial computation fails, or Blender Python is needed. For MCP setup, read chapter 1 and the repository level [MCP installation guide](../reference/MCP_INSTALL.md).
