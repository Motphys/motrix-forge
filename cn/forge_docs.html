Forge Operator 使用文档¶

本文档按 Blender 中的 Forge UI 布局和功能拆分为独立章节，适用于 Creation、Definition、Properties 及与其同区域的辅助 Operator。

推荐阅读顺序¶

  • 第一次使用：依次阅读第 0～9 章；遇到问题时查看最后一章。
  • 按界面查找功能：从上面的章节导航进入对应 UI 分组。
  • 导入与导出：查看第 8 章；凸分解：查看第 9 章。
  • 按钮灰色：查看第 0 章；目标顺序错误、惯量计算失败或编写 Blender Python：查看第 10 章。
